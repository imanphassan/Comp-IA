# Tools, Technologies, Techniques & Design Methodology

## Frontend

- **React 18** – JavaScript library for building user interfaces
- **React Router DOM** – Client-side routing and navigation
- **Vite** – Fast build tool and development server
- **Tailwind CSS** – Utility-first CSS framework for styling
- **Axios** – HTTP client for API requests
- **Leaflet / React-Leaflet** – Interactive map library for displaying EV charging stations

## Backend

- **Python 3** – Primary backend programming language
- **Flask** – Lightweight web framework for REST API
- **Flask-CORS** – Cross-Origin Resource Sharing support
- **SQLAlchemy** – ORM (Object-Relational Mapping) for database operations
- **SQLite** – Lightweight relational database
- **JWT (PyJWT)** – JSON Web Tokens for authentication
- **Werkzeug** – Password hashing and secure file handling

## Development Tools

- **npm** – Package manager for frontend dependencies
- **pip** – Package manager for Python dependencies
- **Git** – Version control system

## Techniques

- **RESTful API Design** – Structured endpoints for CRUD operations
- **Token-based Authentication** – JWT for secure admin access
- **Client-side Filtering** – Real-time search and filter without server requests
- **File Upload Handling** – Image uploads with validation and secure storage
- **Responsive Design** – Mobile-friendly layouts using Tailwind's responsive utilities
- **Component-based Architecture** – Reusable React components
- **State Management** – React hooks (useState, useEffect, useContext)
- **Form Validation** – Both client-side and server-side validation

## Design Methodology

- **Single Page Application (SPA)** – Seamless navigation without full page reloads
- **Separation of Concerns** – Distinct frontend and backend codebases
- **MVC Pattern** – Models, Views, and Controllers in Flask backend
- **DRY Principle** – Reusable components and utility functions
- **Progressive Enhancement** – Core functionality works, enhanced features layer on top

## External Services

- **OpenStreetMap / Stadia Maps** – Map tile provider for charging station map
- **CARTO** – Alternative map tile styling
